# 羊毛团实测 · 四项实测卡

每张卡跟踪一个读者要做的决定。测试前填前两项，保留当时写下的判据；测试后把原始材料交给笔者。遇到多条独立宣称，可在同一卡内分别编号。

| 项目 | 填写内容 |
| --- | --- |
| 1. 作者原话与前提 | 引用原句，附原帖或文档链接、对应段落和观察日期。写明作者使用的入口、样本类型与明示条件，以及读者想据此做的决定。 |
| 2. 事先定下的通过条件 | 写清准备拿什么测、怎样算通过、拿什么作对照。比如测访谈整理时，预先选定原片中嘉宾改口的时间戳，要求成稿保留更正后的数字及正确说话人。此处仅示范判据。 |
| 3. 实际对照结果 | 记录实际入口、版本、模型、配置、套餐、输入和可重做的步骤。按运行顺序记下首次输出、对照输出、失败、重试和人工修改；附耗时与实际扣费，未知标明未知。按原判据说明哪些通过、哪些没通过。 |
| 4. 结论对应的证据 | 每条写「结论 → 原件位置 → 输出或截图位置 → 适用范围」。定位到页、行、格、时间戳或具体附件。结论若依赖一次补测，保留补测前后的两份输出。 |

交接时，笔者打开卡上的原件和成品，独立核对标题里的判断。看到矛盾，把具体问题退回执行手，例如「原片在此处改了数字，请核对第一次输出是否沿用了旧数字」。拿到记录再定稿。

验收：四项填全；每个正文段落能指出依据；最终正文按[技能的字数口径](../SKILL.md#交稿前的字数回执)运行脚本，至少 3000 个汉字。回执附实际计数和对应的终稿，不计本卡。
