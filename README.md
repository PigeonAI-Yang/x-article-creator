# X Article Creator · 羊毛团的免费中文写作 Skill

收藏了一个好项目，真要写推荐时，第一句却只想得到「发现一个宝藏工具」？把链接交给 `x-article-creator`，让它先帮你找出一个值得写透的问题：**读者手里哪件具体的活，用它能怎么做？**

这套开源技能给在 X 上推荐工具、文章和开源项目的人用。从挑选题、写长文，到准备封面、步骤图和引流短帖，一套写作流程可以反复用。源码只有一份 Markdown，打开就能读，也能改成自己的写法。[查看写作规则](./SKILL.md) · [羊毛团官网](https://ymtuan.live)

## 拿什么来写

一个链接就可以用来选题。想写一篇实测稿，可以再给一组输入、实际输出和关键截图。比如介绍 PDF 转 Markdown 的项目，选一份带跨列表头的 PDF，让读者看到转换前后的表格。表头留在了哪一列，比支持多少种文件格式更能说明它是否适合眼前的活。

## 安装与使用

把本仓库克隆到你常用的技能源码目录：

```sh
git clone https://github.com/PigeonAI-Yang/x-article-creator.git
```

将 `x-article-creator` 整个目录放入你的助手扫描的 `skills` 目录，或在那里创建指向源码目录的链接。DeepSeek Harness 和 Codex 可以共用同一份源码。也可以直接打开 [SKILL.md](./SKILL.md)，让助手按其中的流程写稿。

在能识别该技能的助手中，可以这样开始：

> 用 x-article-creator 推荐这个 PDF 转 Markdown 项目。附件里有原 PDF、转换结果和截图。读者最关心表头会不会错位，请用同一张表讲清怎么检查，给我长文、引流短帖和回贴文案。

## 一次交稿包含什么

- **标题与正文**。先试结果型和痛点型两个标题方向，再按「是什么 → 怎么做 → 常见问题」展开。教程每一步写清入口、输入，以及读者看到什么才算成功。
- **封面与步骤图**。用本期结果做封面，让截图对应实际步骤。出图和截图使用宿主助手已有的工具，缺少的证据会在交稿时标明。
- **短帖与回贴**。短帖先展示一个值得追问的结果；长文上线后，核对永久链接，再把读者引到最有用的那一节。
- **来源与字数回执**。数字和第一人称实测保留出处。完整长文默认至少 3,000 个正文汉字，由助手对终稿实际计数。
